│ 传统经验 {G0: "...", G1: "...", ...}                         │

│ "使用高熵起始词最大化信息增益"                               │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ L2 元策略级 (2 个)                                           │
│ "Principle: 优先投资于信息获取和结构化表示..."               │

## 💡 关键技术点总结

### 1. 分层经验生成机制

```
阶段: 训练时，每个 epoch 后
方法: LLM 多层抽象

L0 (案例级):
  - 输入: 传统经验
  - 方法: 直接转换 + 去重
  - 数量: ~30 个（3 epochs × 10 个/epoch）

L1 (模式级):
  - 输入: 5 个 L0
  - 方法: LLM 抽象通用策略
  - 数量: ~6 个（30 L0 ÷ 5）

L2 (元策略级):
  - 输入: 3 个 L1 + 约 15 个源 L0
  - 方法: LLM 提炼跨任务原则
  - 数量: ~2 个（6 L1 ÷ 3）
```

### 2. Wordle 简洁历史优化

```
优化前:
  - 使用完整对话历史（save=True）
  - Prompt 指数增长（Round 10 约 5000+ 字符）
  - Token 消耗: ~3000/局

优化后:
  - 手动维护简洁历史（save=False）
  - Prompt 线性增长（Round 10 约 275 字符）
  - Token 消耗: ~400/局
  - 节省: 87%
```

### 3. 环境无关的经验提取

```
旧逻辑:
  - 只处理 avg_score 在 (0, 1) 的"部分正确"组
  - Wordle (0/1 reward) 被过滤 75%+

新逻辑:
  - 处理所有问题组（全对、全错、部分正确）
  - 选择代表性样本（best + worst + 补位）
  - 反事实对比（为什么 A 比 B 好）
```
