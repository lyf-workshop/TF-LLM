# 文档模板

本目录包含 youtu-agent 项目的标准文档格式模板，用于保持文档风格的一致性。

## 模板文件

| 模板 | 文件名 | 适用场景 |
|------|--------|----------|
| **格式 A：使用指南** | `FORMAT_A_GUIDE.md` | 游戏使用指南、功能使用教程 |
| **格式 B：故障排除** | `FORMAT_B_TROUBLESHOOTING.md` | Bug 修复、问题诊断文档 |
| **格式 C：概念说明** | `FORMAT_C_CONCEPT.md` | 技术原理、机制说明文档 |
| **格式 D：命令参考** | `FORMAT_D_REFERENCE.md` | 命令速查、API 参考 |
| **格式 E：归档记录** | `FORMAT_E_ARCHIVE.md` | 开发日志、实验分析报告 |

## 使用方法

1. 复制对应的模板文件
2. 根据模板中的 `[占位符]` 和注释填写内容
3. 保持章节结构和格式风格不变
4. 删除模板中的说明性文字

## 模板说明

### 格式 A：使用指南（Guide）

用于编写面向用户的操作指南，包含：
- 快速开始（5分钟体验）
- 完整流程（详细步骤）
- 配置说明
- 常见问题

**示例**：`docs/guides/korgym/wordle.md`

---

### 格式 B：故障排除（Troubleshooting）

用于汇总所有错误和解决方案，格式为：
- 问题现象
- 根本原因
- 修复方案
- 验证方式

**示例**：`docs/troubleshooting/index.md`

---

### 格式 C：概念说明（Concept）

用于解释技术概念和工作原理，包含：
- 概念定义
- 工作原理（含流程图）
- 代码位置
- 配置参数
- 使用示例

**示例**：`docs/concepts/hierarchical_experience.md`

---

### 格式 D：命令参考（Reference）

用于提供命令速查表，格式为：
- 命令用途
- 完整命令
- 参数说明
- 注意事项

**示例**：`docs/reference/commands.md`

---

### 格式 E：归档记录（Archive）

用于归档开发日志和实验分析，包含：
- 背景和动机
- 问题描述/分析过程
- 解决方案/结论
- 验证结果

**示例**：`docs/archive/changelogs/2026-01-22-wordle-fixes.md`

---

## 文档编写原则

1. **简洁明了**：用最少的文字传达最多的信息
2. **结构清晰**：使用统一的章节结构和标题层级
3. **代码可运行**：所有命令和代码示例都应该可以直接运行
4. **链接完整**：文档间相互引用，形成知识网络
5. **持续更新**：代码变更后及时更新相关文档

## 贡献指南

在创建新文档时：
1. 选择合适的模板
2. 遵循模板格式
3. 确保所有链接有效
4. 在 `docs/` 对应目录下创建文件
5. 更新父目录的 `index.md` 或 `README.md`
